# Someday

> 🚧 Work in Progress

Someday is a mobile application designed to simulate the full online shopping experience without requiring users to spend real money.

The idea came from wanting a realistic alternative to impulsive online shopping. Instead of making an actual purchase, users can go through the entire experience — searching for products, adding items to a cart, checking out, making a simulated payment, tracking an order, and receiving a virtual delivery.

The goal is to make the experience feel as realistic as possible while helping users avoid unnecessary spending. Money that would otherwise have been spent can instead be saved and used someday for something that genuinely matters.

## Planned Experience

Someday aims to recreate the full e-commerce journey:

- Product search and discovery
- Product browsing
- Dream Cart / saved items
- Simulated checkout
- Virtual payment experience
- Order confirmation
- Delivery tracking
- Order history
- User profile
- Virtual card interface

## Running the Project

### 1. Install dependencies

```bash
npm install
```

### 2. Start the Expo development server

```bash
npx expo start
```

This will start the Expo development server and display options for running the application.

You can open the app using:

- Expo Go on a mobile device
- Android emulator
- iOS simulator
- Web browser, where supported
